# 神託の社 プライバシーポリシー

最終更新日：2026年11月3日

本プライバシーポリシーは、Like Sea Diveが提供するiPhone・iPadアプリ「神託の社」に適用されます。

## 1. 取り扱う情報

本アプリでは、名前またはニックネーム、生年月日、鑑定結果、参拝記録、ゲームの進行状況、設定情報などを、アプリの機能を提供するために利用します。

これらの情報は原則として利用者の端末内で処理・保存し、運営者が管理する外部サーバーには送信しません。

## 2. アプリ内課金

詳細鑑定の買い切り購入にはAppleのアプリ内課金を利用します。決済および購入履歴はAppleが管理し、本アプリは購入状態の確認と復元にAppleの仕組みを利用します。運営者がクレジットカード情報を取得することはありません。

## 3. 広告・トラッキング

現行バージョンでは、広告SDK、第三者アクセス解析SDK、広告目的のトラッキング機能を導入していません。

## 4. データの削除

利用者はアプリの設定画面から、端末内の入力情報や参拝・鑑定記録を削除できます。Appleが管理する購入済みの権利は削除されません。

端末のバックアップに含まれるデータについては、利用者のバックアップ設定に従います。

## 5. 外部サービス

購入および購入の復元にはAppleのサービスを使用します。Appleによる情報の取り扱いについては、[Appleのプライバシーポリシー](https://www.apple.com/jp/legal/privacy/)をご確認ください。
